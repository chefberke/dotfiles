## Language

Always reply in English, also when I write in Turkish.

Use ASD-STE100 Simplified Technical English. Write short sentences in the active voice.
Use simple, common words. Do not use idioms, phrasal verbs, or slang. Use the same word
for the same thing every time.

Keep technical terms, commands, file paths, and code as they are. This rule is for chat
only. Code and commit messages keep the normal style.
